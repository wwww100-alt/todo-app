# Описание прецедентов системы «Список дел»

## Прецедент «Добавить дело»
- **Цель:** зафиксировать новое дело в списке.
- **Основной сценарий:** пользователь выбирает пункт меню 1, вводит название и срок.
- **Альтернативный сценарий:** название пустое — программа выводит сообщение об ошибке и повторяет ввод.

## Прецедент «Просмотреть список дел»
- **Цель:** увидеть все текущие дела и их статус.
- **Основной сценарий:** пользователь выбирает пункт меню 2, программа выводит список всех дел с отметкой «выполнено» или «не выполнено».

## Прецедент «Отметить дело выполненным»
- **Цель:** изменить статус дела на «выполнено».
- **Основной сценарий:** пользователь выбирает пункт меню 3, вводит название дела, программа меняет статус и сохраняет изменения.
- **Альтернативный сценарий:** дело с таким названием не найдено — программа выводит сообщение об ошибке.

## Прецедент «Удалить дело»
- **Цель:** убрать дело из списка.
- **Основной сценарий:** пользователь выбирает пункт меню 4, вводит название дела, программа удаляет его и сохраняет изменения.
- **Альтернативный сценарий:** дело не найдено — сообщение об ошибке.

## Прецедент «Сохранить данные» (служебный)
- **Цель:** сохранить текущее состояние списка дел в файл.
- **Основной сценарий:** выполняется автоматически после каждого изменения (добавления, удаления, отметки).
