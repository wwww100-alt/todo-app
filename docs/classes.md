# Описание классов

- **Task** — модель одного дела: название, срок, статус. Метод `mark_done()` меняет статус на выполненный, `__str__()` возвращает строковое представление для вывода.
- **TaskManager** — управляет списком дел: добавление, удаление, получение списка, поиск по названию.
- **TaskStorage** — слой хранения: загружает и сохраняет список дел в файл.
- **ConsoleUI** — консольный интерфейс: отображает меню, принимает ввод, выводит результаты.

## Связи
- `ConsoleUI` → `TaskManager` — ассоциация (UI использует менеджер).
- `TaskManager` → `Task` — агрегация (менеджер содержит список дел).
- `TaskManager` → `TaskStorage` — зависимость (менеджер использует хранилище для сохранения/загрузки).
